# CLAUDE.md / AGENTS.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a Doom Emacs private configuration directory (`~/.config/doom`). Doom Emacs is a configuration framework for Emacs that uses a modular system with lazy-loading.

## Key Files

- **init.el** - Declares which Doom modules are enabled (completion, UI, editor, languages, etc.)
- **config.el** - Personal configuration, keybindings, and customizations loaded after Doom
- **packages.el** - Declares additional packages to install via straight.el
- **custom.el** - Auto-generated by Emacs customize system (avoid manual edits)

## Commands

After modifying `init.el` or `packages.el`:
```bash
doom sync
```

Rebuild and sync:
```bash
doom sync -u
```

Check for issues:
```bash
doom doctor
```

## Configuration Patterns

Doom uses specific macros for configuration:
- `after!` - Run code after a package loads
- `use-package!` - Configure packages (wrapper around use-package)
- `map!` - Define keybindings
- `setq-hook!` - Set buffer-local variables via hooks
- `add-hook!` / `remove-hook!` - Hook management
- `load!` - Load external elisp files

## Enabled Modules

Key enabled features: evil (vim keybindings), vertico + corfu (completion), org-mode with roam2/pomodoro, magit with forge, tree-sitter, LSP for Go/Java/Docker/Terraform, vterm terminal.

## Custom Packages

Additional packages in `packages.el`:
- `org-ql`, `org-super-agenda` - Advanced org queries
- `mermaid-mode` - Diagram support
- `sops` - Secret encryption
- `claude-code-ide` - Claude Code Emacs integration

## Claude Code IDE Integration

This config includes `claude-code-ide.el` setup with keybindings under `SPC A`:
- `SPC A a` - Claude menu
- `SPC A c` - Start Claude
- `SPC A p` - Send prompt
- `SPC A C` - Continue
- `SPC A t` - Toggle recent

## Org-roam Setup

Org files are in `~/Documents/org-roam` with:
- Capture templates for todos, notes, journal entries
- Daily notes in `daily/` with yearly datetree structure
- Reference capture for web pages in `sites/`
